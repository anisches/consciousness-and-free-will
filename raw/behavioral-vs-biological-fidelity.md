# Behavioral vs. Biological Fidelity
Behavioral fidelity (producing the correct output for a given input) is often achievable using biologically arbitrary wiring. A striking example is a *C. elegans* connectome model trained with deep reinforcement learning that produces realistic *Drosophila* walking behavior, despite having fundamentally different internal representations (Brunton et al., 2026).

This "meaningless" fidelity highlights the need for population-level metrics that can verify whether a model's internal computation aligns with biology, independently of its task performance.
