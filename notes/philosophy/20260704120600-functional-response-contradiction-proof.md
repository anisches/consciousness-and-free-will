# Functional Response Contradiction Proof

The proof of the **Free Will Theorem** is a proof by contradiction.

## 1. Initial Hypothesis
Assume that a particle's response is a function of the past history of the universe. 
Let $A(x,y,z,w, \alpha)$ be the response of particle $a$ on Earth.
Let $B(x,y,z,w, \beta)$ be the response of particle $b$ on Mars.
- $(x,y,z)$ are Experimenter A's choices.
- $w$ is Experimenter B's choice.
- $\alpha, \beta$ are the past histories (information bits).

## 2. Refining the History
Conway addresses "bad" bits (information that depends on the experimenters' free choices) by replacing them with a finite set of "good" bits—pre-calculated values for every possible choice. This allows $\alpha$ and $\beta$ to be treated as independent of the free choices.

## 3. Applying Axioms
- **FIN Axiom**: $A$ cannot depend on $w$, and $B$ cannot depend on $(x,y,z)$.
- **TWIN Axiom**: If $w = x$, then $B(w) = A_1(x,y,z)$.
- **SPIN Axiom**: The triple $A(x,y,z)$ must be a permutation of $(1, 0, 1)$.

## 4. Reducing to a Function of Direction
By specializing $\alpha$ and $\beta$ to a specific instant (snapshot) before the choice is made, they become constants. 
- $B(w)$ becomes a function of a single direction $w$.
- Because $B(w) = A_1(x,y,z)$ when $w=x$, the values of $B$ for any three orthogonal directions must satisfy the 101 law.

## 5. Contradiction
The result is a function $B(w)$ that assigns $0$ or $1$ to every direction and satisfies the SPIN axiom's 101 law. However, the [[20260704120500-kochen-specker-paradox-functional-impossibility]] proves that no such function exists.

## 6. Conclusion
The initial hypothesis (that the response is a function of the past) must be false. The particle's response is "free" in the same sense that the experimenter's choice is assumed to be free.
