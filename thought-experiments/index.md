# Thought Experiments

## Purpose

Each thought experiment should be classified by the specific pressure it creates. Avoid treating all of them as direct evidence for or against one large theory.

## Initial Index

| Thought Experiment | Area | Tests |
| --- | --- | --- |
| Mary the color scientist | consciousness | physical knowledge vs phenomenal knowledge |
| Philosophical zombies | consciousness | conceivability, function, experience |
| Chinese room | mind/AI | syntax vs semantics, understanding |
| Inverted spectrum | consciousness | functional sameness and qualitative difference |
| Frankfurt cases | free will | responsibility without alternate possibilities |
| Manipulation cases | free will | sourcehood and causal history |
| Consequence argument | free will | determinism and ability to do otherwise |
| Libet veto | agency/neuro | initiation vs conscious control |
| Split brain | consciousness/agency | unity of mind and agency |
| Teletransportation | identity | continuity, personhood, survival |

## Template

- setup
- target intuition
- conclusion it is supposed to support
- strongest objection
- what it does not show
- related empirical cases
