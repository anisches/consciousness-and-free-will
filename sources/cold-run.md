# Cold Run Source Map

This is the first uncommitted-to-any-position pass. The job is to classify sources, not decide the debate.

## Classification Legend

- Evidence/type: primary text, philosophical argument, empirical study, review/survey, clinical case family, or thought experiment.
- Debate family: consciousness, free will, determinism/compatibilism, agency/volition, moral responsibility, personal identity, or AI/mind.
- Link/DOI: use only stable links that have been checked. If uncertain, mark it "link needed" or "verify DOI/link".
