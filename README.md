# Consciousness and Free Will

A public research notebook on consciousness, agency, volition, and the free-will debate.

The project starts from primitives: the historical questions, the major positions, public essays worth using for orientation, and the neuroscience results that shaped the debate. The goal is not to defend a view early. The first pass is classification, source collection, and conceptual hygiene.

## Working Questions

- What is consciousness: experience, access, reportability, integration, self-modeling, or something else?
- What is free will: metaphysical freedom, practical agency, moral responsibility, control, or authorship?
- Which parts of the debate are philosophical, neuroscientific, psychological, computational, or semantic?
- Which thought experiments clarify the problem, and which only rename it?
- What do neuro results actually show about agency and conscious intention?

## Current Source Buckets

- Historical primitives: Aristotle, Augustine, Hume, Kant, Frankfurt, Strawson, van Inwagen, Fischer/Ravizza, Kane, Pereboom.
- Consciousness theory: Nagel, Jackson, Chalmers, Block, Dennett, Baars, global neuronal workspace, IIT, higher-order theory, recurrent processing.
- Neuroscience of agency: readiness potential, predictive decoding, accumulator models, sense of agency, intentional binding, split-brain work, alien hand, and clinical agency disruptions.
- Public orientation: SEP, IEP, The Brains Blog, and author-maintained resources.

## Method

Every source should eventually answer four questions:

- What is the source actually claiming?
- What evidence or argument supports it?
- What question does it not answer?
- Which neighboring debate does it get confused with if read carelessly?
